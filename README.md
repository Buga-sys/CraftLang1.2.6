# CraftLang

**CraftLang (.cl)** — русскоязычный универсальный язык программирования.

CraftLang создаётся для разработки игр, сайтов, приложений и других программ. Его главная особенность — возможность писать код почти полностью на русском языке.

## Возможности

- Русскоязычные команды.
- Поддержка HTML js py lua и CSS в одном `.cl`-файле.
- Создание 2D- и 3D-игр.
- Разработка сайтов и приложений.
- Один скрипт для логики проекта.
- Собственный интерпретатор CraftLang.

## Пример

```text
cl

пусть имя = "Craft"
пусть возраст = 1

скажи "Привет, " + имя

если возраст >= 1 тогда
    скажи "Проект запущен!"
end

js
    имя = "CraftLang";
    возраст = 1;

    console.log("Привет, " + имя);
    console.log("Возраст: " + возраст);

    if (возраст >= 1) {
        console.log("Проект запущен!");
    }
end

html
    <h1>Привет, мир!</h1>
    <p>Мой первый сайт на CraftLang</p>
end

css
    body {
        background: black;
        цвет: white;
    }
end
```
py
    имя = "Craft"
    возраст = 1

    скажи(f"Привет, {имя}!")
    скажи(f"Возраст проекта: {возраст}")
end

lua
    имя = "Craft"
    возраст = 1

    скажи("Привет, "имя"!")
    скажи("Возраст проекта "возраст"")
end

## Статус проекта

CraftLang находится в разработке.

Цель проекта — создать собственный язык программирования, доступный начинающим и опытным разработчикам.

## Расширение файлов

Файлы CraftLang используют расширение:

`.cl`
`.craftlang`
